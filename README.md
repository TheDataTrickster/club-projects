# Клуб менеджеров

Лендинг клуба внутри комьюнити людей, которые изучают ИТ-профессии и хотят научиться управлять собой, командой и продуктом.

## О проекте

**Клуб менеджеров** — гибридное пространство практики (онлайн и офлайн):

- встречи с действующими ИТ-специалистами
- воркшопы
- кейс-клуб
- обсуждение бизнес-литературы

Это не школа и не курс, а комьюнити внутри комьюнити: место, где можно ошибаться, пробовать, спрашивать и расти вместе.

Подробная концепция и миссия — в [`description.md`](./description.md).

## Стек

Статический лендинг без сборки:

- `index.html` — разметка
- `styles.css` — стили в духе [Школы 21](https://21-school.ru/) (тёмный фон, лаймовый акцент, крупная типографика)
- `script.js` — мобильное меню, sticky-хедер, появление блоков при скролле

## Как открыть

Из корня проекта:

```bash
# вариант 1 — просто открыть файл в браузере
open index.html

# вариант 2 — локальный сервер (удобнее для проверки якорей и путей)
python3 -m http.server 5173
```

Затем откройте [http://localhost:5173](http://localhost:5173).
